# comercialAPI

## Requisitos

- JDK 25 (LTS) para compilar e executar a aplicação.
- O Maven Wrapper incluído no repositório (`./mvnw`), que fornece Maven 3.10.0.

## Compilação e testes

```bash
./mvnw clean test
```

O nível de compilação Java 25 está configurado em `pom.xml` por meio da propriedade
`java.version`.
